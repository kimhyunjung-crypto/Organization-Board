# 역할별 개발 실행 기록

## 요청과 기준

2026-09-15 사용자 요청에 따라 orchestrator가 GPT-5.6-sol(xhigh)와 Antigravity CLI의 `gemini-3.8-flash-high`를 조율한다. 개발 순서와 완료 판정의 기준은 [개발 계획](plan.md)이다. 시험 구현을 제품 구현 완료로 계산하지 않는다.

착수 시 `D:\org-board`에는 `doc/`의 문서 5개와 커밋이 없는 Git 저장소만 존재했다. 이전 코드의 삭제 원인이나 다른 위치의 존재는 확인되지 않았다. 원본 문서를 첫 Git 커밋으로 보존하고 개발을 시작한다.

## 역할과 수정 경계

| 담당 | 책임 | 초기 소유 파일 |
|---|---|---|
| Orchestrator | 선행 조건 확인, 인터페이스 합의, 통합 검토, 검증, Story 상태와 커밋 관리 | 개발·검증 기록, 통합 수정 |
| GPT-5.6-sol / xhigh | S00.01 앱·타입·테스트 환경, 이후 XLSX 파서 시험 | package/lockfile, 빌드 설정, src/, tests/ |
| Antigravity / gemini-3.8-flash-high / high | S00.01 로컬 자산·출처·체크섬, 이후 이미지 좌표·검출 시험 | public/assets/, 자산 스크립트, THIRD_PARTY_NOTICES.md, doc/assets.md |

공유 파일은 동시에 수정하지 않는다. 후속 작업을 배정할 때 모듈별 소유권을 다시 명시한다. 의존성 변경과 최종 통합은 단일 담당자가 처리한다. 실제 직원정보와 사진은 에이전트 입력이나 시험 데이터로 사용하지 않는다.

## 병렬 가능한 범위

- **S00.01 내부:** 앱·검증 환경과 자산 출처 조사·다운로드를 병렬 수행한다. MediaPipe WASM 복사는 패키지 설치를 기다린다. 로컬 자산 경로와 manifest 계약을 먼저 공유한다.
- **S00.01 완료 후:** S00.02(XLSX)와 S00.03(이미지·얼굴·좌표)은 서로 독립적이므로 병렬 수행한다. 독립 디렉터리에 구현하고 공용 harness 연결은 순차 통합한다.
- **제품 단계:** 각 Story 내부에서 계약이 확정된 계산 모듈, UI, 검증 fixture를 나눌 수 있다. 선행 Story가 미완료인 제품 기능을 완료했다고 표시하지 않는다.
- **리뷰:** 한 담당자의 구현이 끝나면 다른 담당자가 읽기 전용으로 리뷰할 수 있다. 같은 파일의 동시 수정은 금지한다.

## 순차 실행과 중단 조건

```text
S00.01
  ├─ S00.02 XLSX 시험 ──────────────┐
  └─ S00.03 사진·좌표 → S00.04 PDF·실물 인쇄
                                  ↓
                        S00.05 오프라인·성능
                                  ↓
                        S00.06 디자인·기준 확인
                                  ↓
E01 → E02 → E03 → E04 → E05 → E06 → E07 → E08
```

1. S00.04는 S00.03 완료 후 시작한다. 실제 프린터의 100% 인쇄와 ±0.5mm 실측 없이 완료하지 않는다.
2. S00.05는 S00.02와 S00.04 완료가 필요하다. 자동 시험 성공으로 실물 인쇄 조건을 대체하지 않는다.
3. S00.06에서 잠정 카드 내부 치수, 글꼴 지원, 화면 판단과 FRD 확인 상태를 증거에 따라 기록한다.
4. M0 통과 이전에는 시험용 harness만 개발한다. 이후 각 Epic의 Story 순서는 plan.md §4를 따른다.
5. 사용자 판단이나 실제 장비가 필요한 경우, 먼저 확인 가능한 PDF·시안·측정 안내를 준비하고 필요한 입력과 재개 조건을 기록한다.

## 실행 증적

- `agy.exe models`에서 `gemini-3.8-flash-high` 제공 확인.
- GPT 담당은 full-history fork 대신 모델과 추론 강도를 명시한 독립 sub-agent로 생성했다.
- Antigravity는 `--model gemini-3.8-flash-high --effort high`로 실행한다. 최초 headless 실행의 읽기 권한 거부 후, 작업 폴더·수정 범위를 제한한 지시와 CLI 자동 도구 승인 옵션으로 재실행했다. 전역 설정은 변경하지 않는다.
- 검사 결과와 남은 조건은 [verification.md](verification.md)에 기록한다. 체크박스는 모든 완료 기준을 충족했을 때만 변경한다.
