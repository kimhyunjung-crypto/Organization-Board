# 조직보드 사용자 가이드 (User Guide)

본 가이드는 Windows 환경에서 **조직보드 (Org Board)** 애플리케이션을 실행하고, 조직보드 인쇄용 PDF를 올바르게 생성 및 인쇄하기 위한 사용자 안내서입니다.

> **[참고] 개발 진행 현황 및 사용자 특별 지침 (`테스트는 무시하고 전부 gemini가 빠르게 구현하고 알려줘`)**
> - 최신 사용자 지시에 따라 자동 테스트 실행, 실물 인쇄 측정(±0.5mm 허용오차 게이트), 디자인 시안 게이트 검증을 잠정 보류(deferred)하고 구현을 우선 진행하였습니다.
> - **현재 상태:** 선행 3개 Story(S00.01~S00.03)만 정식 검증 완료(verified) 상태입니다. Product 담당(E01~E06) 제품 코드 구현 및 패키징(S07.03 실행/종료 스크립트)이 완료되어 최종 통합 중이나, 정식 검증 게이트는 보류 상태(not verified)입니다.

---

## 1. 시작 및 종료 방법 (더블클릭 실행)

조직보드는 Windows 환경에서 간편한 원클릭 배치 파일로 제공됩니다.

### 1.1 시작하기 (`start-org-board.cmd`)
1. 시스템에 **Node.js 24**(권장: v24.18.0) 및 **npm 11**(권장: 11.16.0)이 설치되어 있는지 확인합니다.
2. 폴더 내 `start-org-board.cmd`를 더블클릭합니다.
3. 스크립트가 다음 작업을 자동으로 처리합니다:
   - Node.js 및 npm 런타임 설치 여부 확인 (누락 시 명확한 한국어 오류 메시지 출력)
   - 패키지 의존성(`node_modules`)이 없을 경우 `npm ci` 자동 실행
   - 최신 변경사항을 반영한 최적화 프로덕션 번들 빌드(`npm run build`)
   - 로컬 백그라운드 프리뷰 서버(`http://127.0.0.1:4173`)를 숨김 창으로 시작
   - 기본 웹 브라우저 자동 오픈
4. 만약 포트 4173이 외부 타 프로그램에 의해 점유되어 있는 경우, 조직보드는 타 프로세스를 강제 종료하지 않고 명확한 안내 메시지를 표시하며 중단됩니다.

### 1.2 종료하기 (`stop-org-board.cmd`)
1. 작업 완료 후 `stop-org-board.cmd`를 더블클릭합니다.
2. 스크립트가 해당 작업 디렉터리에서 생성한 조직보드 프로세스(PID 및 하위 프로세스 트리)만 식별하여 안전하게 종료합니다.
3. 조직보드와 무관한 외부 프로세스는 절대 종료하지 않습니다.

## 2. 데이터 처리 및 개인정보 안전 원칙

### 2.1 영구 사용자 데이터 미보관 (No Persistent User Data)
- 업로드된 엑셀 파일, 직원 이름, 부서, 직급, 업로드된 사진 및 크롭 좌표는 **오직 브라우저 메모리(RAM) 내 세션 상태**로만 유지됩니다.
- 서버 측 데이터베이스(DB), 백엔드 API, 로컬 하드 디스크 영구 저장소, 외부 클라우드로 어떠한 정보도 전송하거나 보관하지 않습니다.

### 2.2 로컬 데이터 초기화 (Local Data Reset)
- 애플리케이션 내의 **[초기화]** 버튼을 누르거나, 웹 브라우저 탭을 새로고침(F5) 또는 브라우저 창을 닫으면 메모리에 로드된 모든 직원 데이터와 사진 객체(Blob URL 등)가 즉시 파기됩니다.
- 새로운 조직보드를 작업할 때는 언제든지 화면의 초기화 기능을 통해 이전 작업 내용을 즉각 초기 상태로 되돌릴 수 있습니다.

## 3. 중요 주의사항

### 3.1 일본어 글꼴 미지원 안내 (Japanese Font Unsupported)
- 본 시스템의 실제 번들 인쇄 폰트는 **나눔고딕 ExtraBold 800 (`public/assets/fonts/NanumGothic-ExtraBold.ttf`)**입니다.
- **일본어 고유 문자(히라가나, 가타카나, 일본식 약자/신자체 한자)는 공식 지원되지 않습니다(미지원).**
- 직원 이름이나 부서명에 일본어 문자가 포함될 경우 PDF 생성 시 글리프 누락(두부 현상 `□`) 또는 대체 글꼴로 비정상 렌더링될 수 있으므로, 한글 또는 영문 로마자 표기로 입력을 권장합니다.

### 3.2 실물 크기 100% 인쇄 안내 (Actual Size Print)
조직보드는 25mm × 38mm 표준 사진 카드가 A4 가로 규격에 정밀하게 배치되도록 설계되었습니다. 실제 프린터로 인쇄할 때 규격이 왜곡되지 않도록 인쇄 설정에서 다음을 반드시 지켜주십시오:

1. **용지 크기**: **A4** (210mm × 297mm)
2. **용지 방향**: **가로 (Landscape)**
3. **배율/크기 옵션**: 
   - ⚠️ **"용지에 맞춤(Fit to Printable Area / Fit to Paper)" 옵션을 절대 선택하지 마십시오.** (카드가 축소 인쇄되어 25 × 38mm 규격에 맞지 않게 됩니다.)
   - 반드시 **"실제 크기(Actual Size)"** 또는 **"배율 100%"**를 선택하십시오.
4. **여백(Margins)**: '기본(Default)' 또는 '없음(None)' (PDF 내부에 이미 인쇄용 10mm 규격 마진이 포함되어 있습니다.)

## 4. 문제 해결 (Troubleshooting)

- **Q. `start-org-board.cmd` 실행 시 Node.js 오류가 발생합니다.**
  - A. 시스템에 Node.js 24(또는 호환 버전)가 설치되어 있지 않거나 `PATH`에 등록되지 않았습니다. [Node.js 공식 홈페이지](https://nodejs.org)에서 LTS 버전을 설치한 후 다시 시도해 주세요.
- **Q. 포트 4173 충돌 오류가 발생합니다.**
  - A. 다른 프로그램이 4173 포트를 사용 중입니다. 충돌하는 프로그램을 종료하거나, 이전에 실행된 조직보드가 종료되지 않은 경우 `stop-org-board.cmd`를 실행해 보세요.
- **Q. 인쇄된 카드가 너무 작거나 큽니다.**
  - A. 인쇄 대화상자에서 배율이 "실제 크기 (100%)"로 되어 있는지 다시 확인해 주세요.
