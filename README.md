# 조직보드 (Org Board)

Windows localhost에서 직원정보와 사진으로 25 × 38mm 규격 카드가 배치된 A4 가로 인쇄용 조직보드 PDF를 생성하는 로컬 독립형 도구입니다.

> **[안내] 사용자 특별 지시 및 진행 현황 (`테스트는 무시하고 전부 gemini가 빠르게 구현하고 알려줘`)**
> - 사용자 요청에 따라 단위/E2E 테스트, 실제 물리 인쇄 측정(±0.5mm), 디자인 게이트 검증을 잠정 보류(deferred)하였습니다.
> - **구현 및 검증 현황:** 선행 3개 Story(S00.01~S00.03)만 정식 검증 완료(verified) 상태입니다. Product 담당의 E01~E06 제품 코드 구현과 로컬 실행/종료 패키징(S07.03)이 완료되어 최종 통합 완료이나, 정식 검증 게이트는 보류 상태(not verified)입니다.

## 사용자 실행 4단계 (Usage 4 Steps)

일반 사용자는 명령 프롬프트 입력 없이 더블클릭만으로 실행하고 종료할 수 있습니다.

1. **1단계: 실행 환경 확인**
   - 시스템에 **Node.js 24** (v24.18.0 권장) 및 **npm 11** (11.16.0 권장)이 설치되어 있고 환경 변수(`PATH`)에 등록되어 있는지 확인합니다.
2. **2단계: 애플리케이션 시작**
   - 저장소 루트의 `start-org-board.cmd`를 더블클릭합니다.
   - 최초 실행 시 필요한 의존성(`node_modules`)이 없으면 `npm ci`를 자동 실행하고, 최신 프로덕션 빌드(`npm run build`) 후 백그라운드 프리뷰 서버(`127.0.0.1:4173`)를 숨김 창으로 띄우며 기본 브라우저를 자동 실행합니다.
3. **3단계: 웹 브라우저에서 작업 수행**
   - 브라우저(`http://127.0.0.1:4173`)에서 직원 엑셀 파일과 사진을 업로드하고, 얼굴 자동/수동 크롭 및 카드 스타일을 설정한 뒤 인쇄용 PDF를 다운로드합니다.
   - **영구 사용자 데이터 미보관**: 업로드된 직원 정보와 사진은 브라우저 세션 메모리에서만 처리되며 외부 전송이나 로컬 디스크에 영구 저장되지 않습니다.
4. **4단계: 애플리케이션 종료**
   - 작업을 마친 후 저장소 루트의 `stop-org-board.cmd`를 더블클릭합니다.
   - 현재 작업 영역에서 시작된 조직보드 백그라운드 프로세스(PID 및 프로세스 트리)만 식별하여 안전하게 종료하며, 무관한 타 프로세스는 절대 종료하지 않습니다.

## 개발자 가이드

저장소를 받은 개발자가 개발 및 수동 검증을 진행할 때는 다음 명령을 사용합니다.

```powershell
# 의존성 설치 및 로컬 자산 검증
npm ci
node scripts/verify-assets.mjs

# 개발 서버 실행 (localhost:5173)
npm run dev
```

### 검증 스크립트

```powershell
npm run typecheck
npm run lint
npm run test
npm run build
npm run test:e2e
```
